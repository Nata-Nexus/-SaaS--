# -SaaS--
Розробка інтерактивної BI-системи для моніторингу фінансового стану, аналізу динаміки доходу та оптимізації SaaS-платформи.
Аналіз SaaS-метрик та інтерактивний дашбординг

Інструменти: Tableau Public, Tableau Desktop, Excel/CSV data source.

Опис: Створення комплексної BI-системи для моніторингу фінансових і продуктових метрик SaaS-платформи (дохід, підписки, утримання грошового потоку) з метою оптимізації SaaS-моделі.

Завдання:Спроектувала та візуалізувала систему взаємопов'язаних дашбордів для відстеження доходів у розрізі локацій (Location), продуктів (Software Name) та регіонів (APAC, EMEA, USA).
Налаштувала складні обчислювальні поля (Calculated Fields) для аналізу динаміки New MRR (нового щомісячного доходу) та комбінованих графіків відсоткової зміни виручки (% Difference in Revenue).
Розрахувала та візуалізувала продуктові метрики ефективності клієнтської бази: ARPPU (середній дохід на платника) та Paid Users Count (кількість платних користувачів).
Побудувала матрицю фінансового утримання (Revenue Retention by Cohort) на основі місяців першої оплати користувачів (Months Since First Paid).

Результати:Об'єднала розрізнені продуктові дані в єдину аналітичну екосистему з інтерактивними фільтрами (за часом, локацією та софтом) для швидкого прийняття рішень менеджментом.
Виявила ключові драйвери доходу бізнесу (найприбутковіші продукти — Main App та Customer Success, топовий регіон — USA із доходом $643.8K).
Завдяки автоматизованій когортній матриці Revenue Retention забезпечила бізнесу інструмент для прогнозування стабільності грошового потоку (LTV) та виявлення точок фінансового відтоку.
